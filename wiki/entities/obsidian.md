# Obsidian

A local-first PKM app that stores every note as plain-text Markdown on your own machine
(full data ownership, no cloud lock-in), with a graph view, bidirectional backlinks, and a
large plugin ecosystem (as of 2026-06, toolfinder.com / saner.ai). (confidence: high)

Via the Smart Connections plugin it can do LLM-based Q&A over the whole vault using RAG
(local embeddings). Because notes are plain Markdown, Obsidian pairs naturally with the
[[llm-wiki]] pattern and with [[zettelkasten]]-style linked notes — the same plain-text
substrate this vault uses.

Note: avoid the subjective 0–10 "scores" some blog rankings assign; they are one author's
rubric, not objective fact. (confidence: high)
