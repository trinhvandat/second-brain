# Lesson 03: Setting Up Your Development Environment (fetched 2026-06)

Goal: a working setup that runs Java code calling the Claude API before proceeding.

Tools & prerequisites:
- Java 17+ (LTS) — primary course language; Maven 3.8+ build tool
- Anthropic API key (required); Claude Code CLI (agentic assistant)
- Node.js 18+ (MCP servers, Module 03); Python 3.11+ (Agent SDK, Module 02)
- IntelliJ IDEA (recommended IDE)

Key steps:
- Store the key in `ANTHROPIC_API_KEY` env var — never hardcode; set console usage limits.
- Create a Maven project, add the Anthropic Java SDK; `HelloClaude.java` makes the first
  API call using the Haiku model to conserve credits.
- Install Claude Code globally via npm, authenticate via browser login.
- `.gitignore` must include `.env`. All 10 verification checks must pass before Module 01.

Commands:
- `mvn exec:java -Dexec.mainClass="com.yourname.agenticai.HelloClaude"`
- `curl https://api.anthropic.com/v1/messages -H "x-api-key: $ANTHROPIC_API_KEY" ...`
